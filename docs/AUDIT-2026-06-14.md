# Production Audit & Hardening — 2026-06-14

Brutally-honest pre-roadmap audit of the XYZ Crypto foundation (frontend, backend,
auth, dashboard, CMS, DB, uploads, performance, security, build) plus the safe
fixes applied in the same pass. No redesign; working systems left intact.

## 1. What's already strong
- Consistent API contract (`ok`/`fail`/`handleError`), zod on every body, Prisma
  P2021/P2022 → graceful 503.
- Everything degrades gracefully when an integration is unset (Upstash, Resend,
  Supabase Storage, Realtime).
- Sensible caching: home ISR 300, research 120, profile 60 (+`revalidatePath`),
  premium article `force-dynamic`. Indexed queries; chat keyset pagination.
- next/image (AVIF/WebP) with a locked-down `remotePatterns` allowlist.
- Strict TypeScript; CI runs typecheck+lint+test+build; Sentry wired; secrets only
  via `env.ts`.

## 3. What was fixed in this pass
- **Migration resilience + real migration file** (`prisma/migrations/5_post_views_pageview/`,
  idempotent SQL). `getPost` and the dashboard posts query now retry without `views`
  on P2022 (default 0) — no more 404/500 if the migration lags.
- **Per-user rate limits**: new `profile` bucket (10/min/user); avatar + profile
  PATCH/DELETE switched from `admin`(IP) → `profile`(user id).
- **Password reset** returns 502 when delivery fails (enumeration-safe).
- **Signup race** recovers from P2002 by re-reading the winning row.
- **Premium gating** re-checks live `role`/`membership` from the DB for premium posts.
- **Research `content`** capped at 100k chars.
- **Profile photo (both):** hardened upload + a validated **"Use a link"** URL
  fallback (host-allowlisted, saved via existing `PATCH /api/profile`), so photos
  work with or without Supabase Storage. Setup steps in `HANDOFF.md`.
- **Perf:** `PerpChart` visibility-gated polling; `decoding="async"` on ticker logos;
  tuned `sizes` on PostCard / article cover / Hero logo.
- Added `isAllowedImageHost` unit tests. typecheck+lint+test(60)+build all green;
  shared First-Load JS unchanged (159 kB).
